## Overview
この課題は、C言語の標準関数（libc）や、その他実用的な汎用関数を再実装し、独自の静的ライブラリ（`libft.a`）を作成するプロジェクトである。
このライブラリは、今後のC言語を用いた課題において使用可能なライブラリとなる。

## Language & Tools
* **Language**: C 
* **Build**: Makefile (`make`, `cc`, `ar`) 

## What I Learned
このプロジェクトを通じ、低レイヤのプログラミングおよびシステム開発の基礎となる以下のスキルを習得した。

* **標準ライブラリの実装**:  
`man` の仕様に厳密に従い、文字列操作やメモリ操作の関数を再実装し、ポインタの振る舞いやメモリ空間の扱いを習得した。


* **厳格なメモリ管理**:  
動的メモリ割り当て（`malloc`）を使用した実装において、メモリリークやセグメンテーションフォールトを発生させないコード設計と、適切なメモリ解放（`free`）の習慣を習得した。


* **データ構造の実装（Bonus）**:  
`t_list` 構造体を定義し、単方向連結リストの作成、要素の追加、削除、イテレーションなどを行う関数群をゼロから実装した。


* **コーディング規約の厳守:**:  
42のコーディング規約（Norm）を遵守し、可読性が高く、保守性の高いコードを書く訓練を行った。
